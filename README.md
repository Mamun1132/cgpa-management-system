# CGPA Management System

A Flask web application for managing students' semester-wise results. For each student it stores the ID, name, and the CGPA and credit earned in each of 8 semesters.

## Features

- Add a student with results for all 8 semesters
- Update a student's information
- Delete a student
- View all students

## Tech stack

Python, Flask, Jinja2 templates, HTML/CSS, MySQL

## Project structure

```
templates/
  update_student.html   # form to update a student's name and semester results
```
